# 신록의 섬 · 동물 도감 구현 기획서

작성일: 2026.11.12 · 문서 버전: v1.0 · 대상: Unity 게임 내 동물 친구 도감

## 1. 목적과 구현 범위

식물 표본집 옆의 독립 도감. 동물 10종의 외형·성격·등급·능력·관리 범위·등장 컨셉·연출 기록 제공.

포함 범위: 도감 UI, 종별 데이터, 발견·수집 기록, 저장 데이터, 격자 관리 범위 계산, 샘플 생성 도구.

기존 게임 연결 대상: 동물 소환, 정원 배치, 작물 관리, 인벤토리, 재화, 확률 보정, 월드 애니메이션.

## 2. 등급과 관리 범위

식물과 동일한 4단계 등급명과 색상 계열 사용. 동물의 기본 등급은 종별 고정. 식물 등급과 수확 변이는 별도 기록.

| 등급 | 관리 범위 | 너비 × 깊이 | 동물 친구 |
|---|---:|---:|---|
| 일반 | 2칸 | 2 × 1 | 모리·노루, 토리·토끼, 밤이·고슴도치, 소리·다람쥐 |
| 특별 | 4칸 | 2 × 2 | 누리·수달, 나리·나비, 두리·거북 |
| 희귀 | 6칸 | 3 × 2 | 루나·여우, 포리·너구리 |
| 전설 | 9칸 | 3 × 3 | 별이·부엉이 |

등급 배분·범위는 1차 기획안. 높은 등급일수록 관리 영역 확대. 기존 고유 능력 유지. 확률·성장 속도·보상량의 임의 추가 수치 없음.

## 3. 배치와 범위 판정

- 칸 사이 교차점 배치 · 식재 칸 점유 없음
- 너비: 좌우 폭 · 깊이: 바라보는 방향의 줄 수
- 위·오른쪽·아래·왼쪽 90도 회전 · 동일 관리 칸 수 유지
- 경계 밖·장애물 칸 제외 · 다른 칸으로 보충 없음
- 이동·회전·보관 시 이전 효과 해제 후 새 범위 등록
- 여러 칸에 걸친 같은 식물은 개체 ID 기준 한 번만 처리
- 동일 관리 행동과 수동 행동이 겹칠 때 재배 주기별 중복 처리 방지

Unity 격자: +X 오른쪽, +Y 위쪽. 모서리 (0,0)은 식재 칸 (0,0)의 왼쪽 아래 꼭짓점. 웹 도감과 동일하게 너비 3의 아래 방향은 x=-1,0,1, 첫 줄 y=-1. 나머지 방향은 이 패턴의 회전. XZ 평면 게임에서는 정원 좌표 변환 필요.

## 4. 도감 UI

| 구역 | 표시 정보·동작 |
|---|---|
| 왼쪽 목록 | 3열 캐릭터 카드 · 그림·이름·등급·관리 칸 |
| 검색 | 이름·종·등급·ID·능력 |
| 필터 | 전체/등급 · 능력 · 능력 유형 · 전체/수집/미발견 |
| 오른쪽 상단 | 이름·종·등급·초상화·정원 역할·관리 칸·너비×깊이 |
| 컨셉·배치 탭 | 캐릭터 컨셉·외형 컨셉·등장 컨셉·주요 능력·유형·범위 그림 |
| 연출 탭 | 대기·작동·터치·결과 반응 기획 |
| 화면 크기 대응 | 넓은 화면 좌우 배치 · 좁은 화면 상하 배치 · 영역별 스크롤 |

아트 방향: 크림·세이지·브라운의 표본집. 부드러운 손그림과 동물 종별 몸 구조 유지. 현재 그림은 정지 콘셉트 시안이며 월드 이동/행동 애니메이션은 별도 제작.

## 5. 발견·수집과 저장

| 상태 | 공개·기록 규칙 |
|---|---|
| 미발견 | 어두운 실루엣 · 만남 힌트 · 이름/등급 검색 결과에서 숨김 |
| 발견 | 이름·종·등급·캐릭터 및 관리 정보 공개 |
| 수집 완료 | 수집 기록 갱신 · 발견 상태로 되돌리지 않음 |
| 전체 열람 옵션 | 참고용 화면 · 실제 수집 상태 변경 없음 |

종별 ID를 저장 키로 사용. 배열 순서와 무관한 기록 복원. 기본 저장은 전용 PlayerPrefs 키 사용. 기존 게임 저장 체계 연결 시 ExportJson()/ImportJson() 사용. 저장 슬롯마다 Save Key 구분.

## 7. 기존 게임에 연결할 규칙

| 연결 대상 | 처리 규칙 |
|---|---|
| 자동 물주기 | 아직 물을 주지 않은 작물만 처리 · 성장 시작 · 재배 주기당 1회 |
| 자동 수확 | 성숙 작물만 처리 · 수확물 1개 + 같은 씨앗 2개 · 작물 제거 · 일군 빈 밭 유지 |
| 다음 재배 | 씨앗 1개 재파종 · 물주기 필요 · 자동 파종 없음 |
| 성장 보조 | 기존 성장 시스템에 연결 · 미확정 보정 수치 없음 |
| 품질·황금·추가 수확 | 기존 수확 판정에 연결 · 기본 수확 보장 · 식물 기본 등급 변경 없음 |
| 대형 식물 | 관리 칸에 중복 접촉해도 개체 ID 기준 한 번 적용 |

## 9. Unity 설치·연동

1. [Unity 패키지](IsleOfVerdure-AnimalCodex-v1.0.unitypackage?raw=true)를 내려받아 Assets → Import Package → Custom Package에서 가져오기.
2. Tools → Isle of Verdure → 동물 도감 → 샘플 생성.
3. 생성된 AnimalCodexSample 씬을 열고 Play.
4. 기존 게임에서는 Preview All Entries 해제. 발견/획득 이벤트에서 MarkDiscovered()/MarkCollected() 연결.
5. AnimalCarePlacement의 RangeChanged 이벤트와 기존 농장 시스템 연결.
6. 한글 Font를 Inspector에 연결하고 대상 기기에서 글리프·입력·화면 배치 확인.

도감 전용 패키지로 기존 게임의 재배·인벤토리·소환·재화·관리 AI 전체를 대체하지 않음.

## 10. 검증과 남은 확인

C# 전체 컴파일, JSON 10종, 네 등급, 네 방향 16패턴, 너비·깊이, 경계/장애물 제외, 대형 식물 중복 제거, 패키지 바이트 검증 통과.

Unity 편집기 Import/Play와 Unity 6 최종 실행은 미검증. 이 환경의 편집기는 라이선스 미활성이며 Unity 6는 설치돼 있지 않음. 실제 입력, 한글 Font, PlayerPrefs/JsonUtility 실행, 기존 게임 연결, 기기별 빌드는 대상 프로젝트에서 확인 필요.

능력 보정 수치·발동 주기·소환 확률·애니메이션 에셋은 추가 확정 대상. [검증 기록](VALIDATION.txt)과 [설치·연동 안내](START-HERE.ko.txt) 참고.
